# 📋 Task Management App

A simple Task Management App built using **HTML**, **CSS**, and **JavaScript**. It helps users organize their daily tasks with a clean and responsive interface.

## ✨ Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Save tasks using Local Storage
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/task-management-app.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
